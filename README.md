# loment-site

Loment 的官网。静态站，手写 HTML/CSS，没有构建步骤、没有依赖。

站点出**五种语言**：英文（根目录）、简体中文 `/zh/`、日本語 `/ja/`、Русский `/ru/`、
Español `/es/`。**英文是唯一的源**，其余四种是它的译文 —— 所以对外材料的正本仍然只有
一份，译文不会变成第二个事实来源。这份 README 是给维护者的，所以是中文。

## 多语言

**英文页是源，译文页是派生物。** 派生的问题是"源改了、派生物没跟上，而且没人发现"，
所以这里有一个工具专门看这件事 —— 与仓库里 `docs/i18n/glossary.md` §2 的翻译戳、
以及发布清单、自举种子，是同一套办法。

```bash
python tools/i18n_check.py          # 校验
python tools/i18n_check.py --fix    # 把英文的代码块搬进译文、重建 alternate 组与切换器
python tools/i18n_check.py --stamp  # 重盖翻译戳
```

它钉住这些：

| | |
|---|---|
| 齐全 | 五种语言 × 六个页面，没有多余页面 |
| 路径 | `<html lang>` 与目录对得上 |
| `hreflang` | 每页六条 `<link rel="alternate">`（含 `x-default`）**逐字节**正确 |
| 切换器 | 顶栏那个 `<details class="lang">` 逐字节正确，当前语言带 `aria-current` |
| 代码区 | 每块 `<div class="codewrap">…</div>` 与英文**逐字节相同** |
| 结构 | `<section>` 的 class 序列一致 |
| 链接 | 本地链接目标集合一致 —— 译文不得引入新链接，也不得丢掉链接 |
| 翻译戳 | 译文页头的 `source-sha256` 等于英文页"散文面"的 sha256 |

**代码块与命令输出不翻译。** 这是仓库里 `docs/i18n/glossary.md` §3 的既成规矩，
在这里由判据强制：译文里那块代码与英文**逐字节**相同。要改代码，改英文页，
然后 `--fix` 会把新字节搬进四种译文。`<p class="out">` 里的命令输出同理。

**翻译戳过期 = 英文改了、译文没跟上。** 散文面 = 除代码区与语言切换器之外的全部可见
文字（空白归一后按序拼接）。所以改一句英文，四张译文页的戳一起红 —— 那正是要看见的信号，
不是噪音。把译文改到跟上，再 `--stamp`。

**站址只写在一个地方** —— `tools/i18n_check.py` 顶部的 `ORIGIN`。换域名时改那一行，
跑 `--fix`，30 个页面的 `hreflang` 会一起重写，跑不出"漏掉某一页"这种形状。

**加一个页面要动的地方**（今天**工具只管 head 段、顶栏切换器与代码块，不管导航**）：

1. `tools/i18n_check.py` 的 `PAGES` 加一条；
2. 五种语言各写一份；
3. **顶栏导航要在 30 个页面里各加一行** —— 导航是手写的，而且各语言的"入门/示例"
   那两项文字不同，所以不能靠工具统一生成。链法是页内相对（`zh/` 里也写 `libl.html`，
   不是 `../libl.html`）；**只有仓根资源**（`style.css`、`mark.svg`）才带 `../`。
   插错位置这件事发生过一次：正则先撞上导航里那条 `lompi` 链接，于是新项落到了
   第一个 `</a>` 后面、跑到别的条目中间去了 —— 判据因此从"比链接集合"改成
   **按文档顺序逐条比**，这类挪位子现在会红。
4. 首页 `Systems` 那一节如果有新条目，**别把条数写进标题**（原来叫 "Three systems"，
   加了第四个就过期了 —— 这正是硬约定第 1 条要防的）。

**字体不带 CJK。** `Bitter` / `Public Sans` / `JetBrains Mono` 只有拉丁字形，
三种栈的末尾都接了系统 CJK 字体（`style.css` 的 `:root`）。这是故意的：CJK webfont
动辄几兆，而读者机器上那几套（苹方 / 微软雅黑 / ヒラギノ / 思源）比一个没人调过的
子集更好。日文另有一层覆盖，免得落到中文字面（macOS 自带 Songti SC，不挡的话
日文页的汉字会用中文字形）。

## `roadmap.html` 与 wiki 的分工（**别让它长成第二份路线图**）

路线图在**两个地方**：官网上这一页，和 wiki 的 `Versions and roadmap`。两处英文 = 漂移风险，
所以分工写死：**官网上这一页只放"形状"** —— 哪一版为了什么、什么已经落地、什么没有；
**细节、逐条状态与版本日志留在 wiki**，页面结尾链过去。往这一页加内容前先问一句
"这该在 wiki 上吗"。

页上必须留的三句：**没有日期**、**没有一样现在能下载**、以及**这个项目不把计划放在公开的
issue 追踪器里**（记成仓里带编号的设计文档，**那些文档是中文的** —— 不知道这件事的人会去
错误的地方找路线图）。

**写路线图之前先核 `origin/main` 的 `docs/210`。** 2026-10-11 踩过一次：wiki 与官网两边都
写着"分代没做、写屏障无处可放"，而 `docs/210` §2.7 记着分代那天早就落地了，当初挡着它的
那条理由（指针只存局部/形参槽）**已经作废** —— 于是官网的 LGC 页与 LVM 页**互相矛盾**。
撤掉一句过期的话时**要写明"这条理由作废了"**，别悄悄删：这个项目连自己撤回过什么都记
（`--stamp` 的规矩也是同一个道理）。

## 视觉方向（2026-10-11 改版）

**取的是 rust 官网那种美学方向，不是它的版式。** 具体差别：字体是
`Bitter`（板衬线标题）/ `Public Sans`（正文）/ `JetBrains Mono`（代码），
**不是**它的 Alfa Slab One + Fira Sans；配色是自己的（墨蓝字 + 白纸 + 一个蓝强调色），
没有搬它的琥珀/靛蓝/绯红。**不要为了"更像"去换字体或抄它的细节** —— 那既侵权，
也让它看起来像山寨。

母题取自 Loment 自己的概念 —— **边界**：封闭的用**实线**框，对外的用**虚线**框
（首页那对 sealed / hosted 面板，即 `.split` 那块）。**全站只有这一处允许虚线**，
所以它读得出来。加新组件时别用虚线。

`.limit` 那个赭石色左规的组件是"诚实边界"的标记，与 wiki 上 `Template:Not shipped`
是同一个装置 —— 全项目一套，别另发明一个。

## 硬约定

**1. 不放会过期的事实。** 这是这个站最容易烂掉的地方 —— 它上一版
（`fujojtop.github.io/FujoOSwebsite/loment/`）在 0.1.4 发布后仍在说"预编译工具链尚未发布"，
还挂着一个"立刻使用"的弹窗。

所以：

- 所有下载链接写 `releases/latest`，**不写版本号**，也不写归档文件名
  （文件名带版本号）；
- **不写**模块数、示例数、内置命令数、语言数这类会随仓库变的计数；
- 版本号只在必须的地方出现，且以仓库为权威。**唯一的例外是 `releases.html`** ——
  那一页的题材**就是**版本，所以页面上写明它是例外，并且**下载按钮仍然指 `releases/latest`**。
  加这一页时最容易做错的一步是"顺手把版本号改成链接或删掉"：那一页这样写是有意的。

**2. 代码示例必须真跑过。** 不要凭语法印象写。跑法：

```bash
# 用发布版（用户实际会拿到的那个）
#   https://github.com/FujoJTOP/loment/releases/latest → linux-x64.tar.gz
loment run examples/hello.lomt
```

`examples/*.lomt` 是站上代码的源。改了 `examples.html` 里的代码就要同步改源文件并重跑 ——
两处不一致的话，源文件就是错的，因为它声称自己对应站上那段。

**3. 已知跑不了的东西，要么不放，要么如实标注。** `examples.html` 末尾那段注记是范例：
capability 不在那四个示例里，因为它在本版**链接不过去**（自举链接器的缺陷，参考实现没事）。
站上不假装它能跑。

**4. 改英文页 = 同时欠四笔译文。** 见上面「多语言」。散文面一动，四张译文页的翻译戳
立刻过期，判据会红 —— 别去把 `--stamp` 当成消红的手段重盖一遍：那正是它要拦住的作弊。
要么把译文改到跟上，要么承认那四页暂时落后（红着）。

## 改与发

改完直接 push 到 `main`，GitHub Pages 从分支直接服务（`build_type: legacy`），
没有 CI、没有生成步骤。push 之前跑一遍：

```bash
python tools/i18n_check.py
```

本地预览：

```bash
python -m http.server 8000
```
